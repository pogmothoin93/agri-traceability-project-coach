# 农产品溯源项目教练 Skill

面向初学者的 FISCO BCOS 农产品溯源教学 Skill，覆盖 Solidity 合约、Java SDK 客户端、HTTP 桥接和网页联调。

## 文件

- `SKILL.md`：技能入口、教学流程和安全边界。
- `references/contract-lecture.md`：来自课程讲义的合约与 Java 客户端说明。
- `references/frontend-backend-bridge.md`：来自课程讲义的 HTTP 服务和前后端桥接示例。

## 使用方式

把整个 `agri-traceability-project-coach` 目录安装到支持 Agent Skills 的工具中。开始对话时描述学生当前任务，例如：“带我完成 AgriTrace 合约的登记和查询，先做一步并等我验证。”

本 Skill 是教学指导材料，不包含 FISCO BCOS 节点、证书、完整工程、网页文件或可直接部署的生产服务。请按 `SKILL.md` 中的安全说明使用；不要公开上传私钥、证书、真实凭证或个人数据。

## 来源和许可

配套参考文件由课程提供者整理，按项目发布者所拥有或获授权的范围使用。第三方依赖、示例代码和平台分别遵循其自身许可；公开复用前请自行核对课程材料和依赖的授权要求。
